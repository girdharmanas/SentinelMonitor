# Sentinel Monitor (`com.sentinel.monitor`)

Flagship Android System Process & Resource Task Manager built with Kotlin 2.0, Jetpack Compose, and Material 3.

## Quick Commands

- **Unit Tests:** `./gradlew testDebugUnitTest`
- **Release APK + Lint (auto-uploads to `artifacts/` & `H:/My Drive/Sentinel Monitor`):** `./gradlew lintVitalRelease assembleRelease`
- **Launch Emulator & Run:** `run.bat`
